\chapter{Experiments}
\label{Experiments}
This chapter presents the experiments conducted on the proposed approach. Section \ref{sec:sim_setup} describes the simulation experimental setup in detail, including the environment and evaluation functions. Section \ref{sec:phys_setup} then details the physical experimental setup, outlining the robotic platform and task configuration. Section \ref{sec:baselines} introduces the robust RL baselines used for comparison, highlighting their relevance to the method. Finally, in Section \ref{sec:exps_and_results}, the proposed method is evaluated in both simulation and on the robotic manipulation task, with the results presented and analyzed. Together, these experiments provide an insightful assessment of the proposed approach, which shows improved performance over the robust RL baselines in the simulated and real-world settings.

\section{Simulation Experimental Setup}
\label{sec:sim_setup}
To evaluate different components of the method in a simulated setting, the Buffalo Gym \parencite{BuffaloGym} environment was utilized. Buffalo Gym is a third-party gymnasium environment that allows experimentation on a variety of bandit formulations. The environment is single-state, but allows the user to generate stochastic reward functions, making it easy to perform analysis on different optimization procedures with a wide range of functions. Experiments were performed on the ``Boundless Buffalo'' which supports continuous action spaces, with some custom modifications to allow for predefined stochastic reward functions. Five such reward functions were produced, shown in Figure \ref{fig:functions} with the corresponding maximum action perturbations shown in Table \ref{tab:max_noises}. These functions were chosen specifically so that the reward landscape requires robustness for success. The fork of the Buffalo Gym repository can be found at the following link: \href{https://github.com/thinclab/buffalo-gym}{https://github.com/thinclab/buffalo-gym}.

\section{Physical Experimental Setup}
\label{sec:phys_setup}
This section describes the experimental setup used to evaluate the proposed method in a robotic manipulation environment. The setup consists of camera-based perception system and a KUKA collaborative robot equipped with an Ubiros gripper. The goal of the system is to autonomously sort recyclable objects within the workspace. The code for this project can be found at: \href{https://github.com/thinclab/recycrl}{https://github.com/thinclab/recycrl}.

\subsection{Robotic Task Description}
The proposed task is to autonomously sort recyclable items within a constrained workspace. The item set consists of aluminum cans and plastic bottles with varying degrees of deformation, which introduces variability in shape and grasp difficulty. The object manipulation is performed with a KUKA LBR iisy $3$ r$760$ collaborative robotic arm equipped with an Ubiros Gentle Pro gripper at the end effector. The context of the workspace is captured using an overhead Oak-D S$2$ RGB-D camera, which provides synchronized color and depth images of the scene. These images are processed and encoded to form the input to the learned policy. The policy outputs continuous control actions for the manipulator, specifying the relative end effector placement. After executing the policy action with the corresponding motion trajectory, the robot automatically closes the gripper to secure the object, moves to the recycling bin, and opens the gripper to release any grasped object. An action is considered successful if the robot is able to securely grasp the assigned object and transport it to the recycling bin. The experimental setup is illustrated in Figure \ref{Workspace}, the overall sorting procedure is summarized in Algorithm \ref{Sorting Loop}, and an example of robot a trajectory is shown in Figure \ref{fig:trajectory}.

\subsection{Context Estimation}
The context of the workspace is obtained using images from an overhead RGB-D camera. When the current context is requested, the camera captures an RGB image and a corresponding depth image of the workspace. The RGB image is passed through a YOLO v$11$ instance segmentation model, which produces pixel-wise masks of the aluminum cans and plastic bottles present in the scene. The YOLO model was trained on a combination of publicly available datasets containing annotated images of general cans and bottles, as well as a custom dataset containing images collected directly from the workspace with manual annotation. Incorporating general and task-specific data enables the model to generalize and maintain accuracy for specific objects with the instance segmentation procedure. 

After obtaining the segmented instances from the RGB image, principal component analysis (PCA) \parencite{PCA} is performed on the mask of each item. PCA provides an efficient method to calculate different geometric properties from the object masks, and is first utilized to compute the centroid. The centroid represents the average position of all the pixels in the object mask, effectively providing a $2$D estimate of the object's center in the image plane. In addition to the centroid, PCA is utilized to calculate the principal axis of each mask, which is used to indicate the orientation of the each object in the image. Figure \ref{State Estimation} provides a visual overview of this process, showing the initial RGB image, the extracted object masks, and the result of the PCA analysis on each mask.

The corresponding depth image is then used to recover the $3$D position of the centroid from its $2$D location in the image. Using the camera intrinsics and a standard pinhole model, the pixel corresponding to the centroid can be projected along a $3$D ray. The depth value at the centroid's pixel represents the distance along this ray, allowing the computation of the object's centroid relative to the camera. This $3$D position is transformed from the camera's local coordinate frame to the robot's global coordinate frame using ROS$2$ transformations. 

The principal axis obtained from PCA defines the object's yaw angle in the robot frame. However, for a complete $6$D pose representation, the pitch angle must also be estimated. To compute the pitch, a two-point method is employed. Two points are selected near opposite ends of the object along the principal axis. The $3$D positions of these points are recovered from the depth image using the same strategy applied to the centroid. Let the vertical difference between the two points be $\Delta z$, and let the planar displacement in the $xy$-plane be $\Delta xy$. The pitch angle is then computed by $\omega=\arctan{\frac{\Delta z}{\Delta xy}}$, which provides a measure of the object's incline relative to the workspace plane. Due to assumed axial symmetry of the bottles and cans, the roll angle is assumed to be zero. Therefore, the full $6$D pose of the each object is defined by the $3$D position of the centroid and the estimated pitch and yaw angles.

\subsection{Context Definition}
\label{Context Definition}
Because the robot focuses on grasping one item at a time, the context representation only includes the $6$D pose of the selected target. This approach greatly reduces the context space by concentrating on the object that is relevant for the current grasping action, rather than including the positions and orientations of all other objects, which is difficult when the number of items is dynamic. Therefore, the context captures the position and orientation of the active object in $3$D space, along with basic contextual information about the scene. Formally the context is defined as:
\[
\mathbf{x}=[x , y, z, \omega, \psi, t, n],
\]
where $x,y,$ and $z$ represent the Eucledian coordinates of the object's centroid, $\omega$ and $\psi$ denote the pitch and yaw angles describing the object's orientation, $t$ represents the object type (e.g., can or bottle), and $n$ denotes the number of objects currently present in the scene. Information about the object type $t$ is necessary as the geometry of aluminum cans and plastic bottles differs. Due to the physical constraints of the workspace, the following bounds are imposed on the context variables: 
\[
\begin{gathered}
x \in [0.20, 0.55], \
y \in [-0.35, 0.35], \
z \in [0.80, 0.95],  \\
\omega \in [-\frac{\pi}{2}, 0], \
\psi \in [-\pi, \pi].
\end{gathered}
\]
These bounds ensure that the context representation includes only feasible poses, preventing the robot from considering impossible positions or orientations during planning or learning.

Because the true context space is continuous, there are infinitely many possible contexts. To significantly reduce the size of the context space for the reward and policy networks, a discretized encoding is introduced. The workspace is first divided into two equal partitions along the $x$ and $y$ axes, producing four spatial quadrants. Each object is assigned a quadrant based on the position of its centroid, compressing all possible continuous $x$ and $y$ values into four discrete values. Then, the pitch angle $\omega$ range is divided into three uniform bins, and the yaw angle $\psi$ range is divided into four uniform bins. Like the quadrant representation, the pitch and yaw bins compress the context representation into a coarse but still meaningful form. The object type $t$ is preserved in the discretized context to maintain the distinction between different recyclable items, while the number of objects $n$ is removed to simplify the encoding and because only a single target is considered. The resulting discretized state is compactly defined as
\[
\mathbf{\hat{x}} = [q, \Omega, \Psi, t],
\]
where $q \in \{ 1,2,3,4 \}$ denotes the spatial quadrant of the object, $\Omega \in \{ 1,2,3 \}$ represents the discretized pitch bin, $\Psi \in \{ 1,2,3,4 \}$ denotes the discretized yaw bin, and $t$ represents the object type. This encoding provides a simplified yet informative summary of the object and reduces the continuous context to a compact representation that is suitable for reward modeling and policy learning. Figure \ref{Discretized Workspace} shows the discretized workspace along with an example of an item mapped to the corresponding quadrant and orientation bins. Although an encoded, discretized context $\mathbf{\hat{x}}$ is produced, the true context $\mathbf{x}$ is preserved to build an absolute pose for the gripper from the relative action (see Section \ref{Action Definition}).

\subsection{Action Definition}
\label{Action Definition}
The actions for the sorting task define how the robotic manipulator moves prior to attempting a grasp. Rather than directly commanding joint angles or the absolute pose of the end effector in the world coordinate frame, each action specifies a relative displacement of the tool center point (TCP) or center of the gripper with respect to the pose of the target object. In other words, the action represents a position and orientation of the gripper relative to the currently selected item. In this formulation, the sole aim of the policy is to learn gripper configurations that lead to successful grasps, without reasoning about the dynamics or planning of the robotic arm. To fully capture the $6$D pose of the gripper in $3$D space, the action is defined as a $6$-dimensional, continuous vector:
\[
\mathbf{a} = [\Delta l, \Delta w, \Delta h, \Delta \varphi, \Delta \omega, \Delta \psi],
\]
where $\Delta l, \Delta w, \Delta h$ denote relative Cartesian offsets in meters along the object's local $x$, $y$, and $z$ axes, respectively, and $\Delta \varphi, \Delta \omega, \Delta \psi$ represent the relative rotations about the $x$, $y$, and $z$ axes (roll, pitch, and yaw), respectively. 
% These rotations can also be referred to as roll, pitch, and yaw.

To execute an action, the agent first computes the absolute pose with component-wise addition between the relative action $\mathbf{a}$ and the preserved, true context $\mathbf{x}$. Once the absolute pose is determined, the agent uses an inverse kinematics \parencite{IK} solver to compute a feasible joint configuration for the target pose. If a valid solution exists, a motion planner generates a trajectory that moves the manipulator from its starting state to the desired grasping position. If no valid solution is found, the action is considered infeasible and assigned a reward of zero.

For example, the action $[0.0, 0.0, 0.0, \frac{\pi}{4}, 0.0, 0.0]$ moves the TCP to the object's centroid with matching pitch and yaw, while introducing a relative roll offset of $\frac{\pi}{4}$ radians or $45^\circ$. Figure \ref{Local Axis} illustrates the object's local axes and provides visual clarification of how each action component maps to translations and rotations about these axes. Because all components of the action are defined in the object's local frame, the same relative action can produce different absolute motions depending on the object's pose in the workspace. This introduces another element of stochasticity into the task, as the same action in the same context may lead to different results.

To ensure that the robot only attempts potentially successful grasps, each component of the relative action $\mathbf{a}$ has the following bounds
\[
\begin{gathered}
\Delta l \in [-0.10, 0.10], \
\Delta w \in [-0.10, 0.10], \
\Delta h \in [-0.01, 0.10],  \\
\Delta \varphi \in [-\frac{\pi}{4}, \frac{\pi}{4}], \
\Delta \omega \in [-\frac{\pi}{4}, \frac{\pi}{4}], \
\Delta \psi \in [-\frac{\pi}{4}, \frac{\pi}{4}].
\end{gathered}
\]
These bounds not only prevent the agent from proposing actions that will never lead to success, but they also shrink the action space significantly. In addition to these restrictions on the relative actions, the computed absolute pose is also clamped to the same bounds defined for the context (Section \ref{Context Definition}).

\subsection{Reward Definition}
Rewards are assigned autonomously to each action executed in the workspace. The reward is binary: actions that result in a successful grasp receive a reward of $1$, while unsuccessful actions receive a reward of $0$. Action success is determined using two criteria: a reduction in the total workspace items, and the measured current load of the gripper. If the number of items in the workspace decreases by one following the action and the gripper current exceeds $150$ mA, the action is classified as successful and assigned a reward of $1$. Otherwise, the action is classified as a failure and assigned a reward of $0$. This dual-condition check ensures that grasp attempts that fail to grab the object are not incorrectly labeled as successful.

A binary reward setup is effective for evaluating the method because multiple actions can yield successful grasps and achieve the maximum reward. However, many of these actions are suboptimal due to inherent uncertainty in the workspace and the grasping process. Rather than optimizing for any action that simply achieves success, the modified objective encourages convergence towards actions that are more optimal and robust to uncertainty. These optimal actions are often located near the center of regions with consistently high rewards. Converging to these regions improves overall performance and helps avoid policies that settle in local optima or rely on highly situational actions.

\subsection{Neural Network Architectures}
\label{sec:nn_arc}
Each approximate reward model in the ensemble is a fully connected Multi-Layer Perceptron (MLP). Each network has two hidden layers consisting of $256$ units, followed by Rectified Linear Unit (ReLU) activations. The model takes the concatenated context and action and outputs a scalar value representing the predicted expected reward. The policy network is also a fully connected MLP with two hidden layers of $256$ units. However, it uses Gaussian Error Linear Unit (GELU) activations after each hidden layer. The policy is initialized with Xavier weight initialization to produce larger variance in the network at first. Because the policy maps contexts to actions, a hyperbolic tangent (tanh) activation is applied to the final layer to bound the outputs within a normalized action range.

\section{Baselines}
\label{sec:baselines}
In order to evaluate the proposed PAR objective, two robust RL baselines were implemented. Much like the PAR objective, these baselines focus on robustness to continuous action perturbations, making them a useful comparison. Although these methods were designed for MDPs or stochastic policies, the objectives of these methods were adapted for the approach in this paper. The two baselines are as follows:
\begin{itemize}
    \item \textbf{Noisy Action Robust MDP (NRMDP):} The NRMDP \parencite{RobustActionMDP} method introduces a mixed policy $\pi_\text{mix}$ which combines the agent's policy $\pi$ and the adversary's policy $\bar{\pi}$ such that 
    \[
    a_t\sim\pi_\text{mix}\big(\pi(s_t), \bar{\pi}(s_t)\big).
    \]
    The mixed policy is defined as
    \[
    \pi_\text{mix}(a|s) = \mathbb{E}_{b\sim\pi(\cdot|s), \ \bar{b}\sim\bar{\pi}(\cdot|s)}
    \Big[\mathds{1}_{a=(1-\epsilon)b+\epsilon\bar{b}}\Big],
    \]
    where $\epsilon$ (denoted $\alpha$ in the original paper) is the adversarial coefficient. The corresponding optimization objective is
    \[
    \pi_{\text{mix}}^{\star} =
    \arg\max_\pi\min_{\bar{\pi}}\mathbb{E}_{a_t\sim\pi_\text{mix}}
    \Big[\sum_{t=0}^{\infty} \gamma^t R(s_t,a_t)\Big]
    \]
    In all experiments, the adversarial coefficient $\epsilon$ was fixed to a value of $0.10$.

    \item \textbf{Adaptive Action Perturbation MDP (A$\mathbf{2}$P):} The A$2$P \parencite{A2P} method extends the NRMDP by making the adversarial coefficient $\epsilon$ adaptive. At each iteration, the Eucledian distance between the agent and adversarial actions is computed as $d$. A moving average of the distance is maintained with the following: 
    \[
    d_j=\zeta \cdot d_{j-1}+(1-\zeta)\cdot d,
    \]
    where $\zeta$ (denoted $\beta$ in the original paper) is the momentum factor. They then define a metric (unnamed) as
    \[
    b=sgn(d_{j-1}-d)\sigma(|d_{j-1}-d|).
    \]
    Finally, the adversarial coefficient $\epsilon$ is updated by
    \[
    \epsilon_{j}=\epsilon_{j-1}+c\cdot b,
    \]
    where $c$ is the learning rate for $\epsilon$. By adapting the adversarial coefficient, the method adjusts the strength of the adversarial perturbation to match the environment. In all experiments, the A$2$P objective was trained with a momentum factor $\zeta$ of $0.50$ and an adversarial learning rate $c$ of $0.10$.
\end{itemize}

\section{Experiments and Results}
\label{sec:exps_and_results}
This section describes the evaluations of the proposed method across the simulation and physical settings and presents the corresponding results. First, the behavior of the different optimization objectives is analyzed in the Buffalo Gym environment, focusing on performance under different noise types. Then, a sensitivity analysis on the uncertainty coefficient $\beta$ is conducted, also in the Buffalo Gym environment, to assess the stability of the approach. And finally, the different optimization objectives are evaluated on the robotic manipulation task, highlighting their effectiveness in a real-world grasping scenario. The experiments demonstrate that the proposed objective is effective and consistently outperforms other robust RL baseline methods.

\subsection{Objective Comparison in Simulation}
First, the different optimization objectives were analyzed in the Buffalo Gym environment. Instead of optimizing with an approximate reward model as described in the proposed framework, the Buffalo Gym functions were treated as the true deterministic reward functions during these experiments, allowing the behavior of each objective to be evaluated. Optimization was performed on the five predefined reward functions (Figure \ref{fig:functions}), with five different initialization seeds per function. After convergence, each policy was evaluated based on the true achieved reward and the average reward under three types of action noise: Gaussian noise with standard deviations equal to $\frac{1}{3}$ and $\frac{2}{3}$ of the maximum perturbation $\delta_\text{max}$, and uniformly random noise within the noise interval. The results for each function across the five seeds are shown in Tables \ref{tab:obj_comp1}, \ref{tab:obj_comp2}, \ref{tab:obj_comp3}, \ref{tab:obj_comp4}, and \ref{tab:obj_comp5}. Additionally, a convergence example for each function is shown in Figure \ref{fig:convergences}.

As expected, the standard RL objective $(\alpha=0.0)$ achieves the highest reward in the absence of perturbations across all five functions. Because this objective solely maximizes reward, it naturally converges to actions at the reward maxima. However, the PAR objective demonstrates superior performance under action noise in every scenario except for two (see Tables \ref{tab:obj_comp3} and \ref{tab:obj_comp4}). This is a result of the performance/robustness tradeoff of the PAR objective, where the resulting actions are high reward and resilient to action perturbations. The optimal value of $\alpha$ depends on the magnitude of the noise, with larger perturbations favoring higher values of $\alpha$. This behavior is intuitive, as noisier scenarios require more robust actions. Both A$2$P and NRMDP show weaker robustness performance in nearly all scenarios when compared to the PAR objective. Since they are optimized with respect to adversarial noise in one direction, the resulting actions may be sensitive to noise in the opposite direction.

\subsection{Sensitivity Analysis in Simulation}
Next, a sensitivity analysis on the uncertainty coefficient $\beta$ from Equation \ref{Penalized Reward} was performed in the Buffalo Gym environment. In these experiments, the Buffalo Gym functions were interpreted as stochastic reward functions, and binary rewards were sampled based on the returned reward probability. After generating $300$ random samples from the reward function, an ensemble of $5$ approximate reward models $(N=5)$ was trained. To encourage diversity in the ensemble, gaps were introduced into the sampling distribution. Policies were then trained using different values of $\beta$, with each policy using the PAR objective with $\alpha=0.5$. After training, the converged policies were evaluated using the true expected reward function to measure the actual achieved performance. The analysis was performed on three reward functions with three randomization seeds each. The results for each function across the three seeds are shown in Tables \ref{tab:sens_ana}, \ref{tab:sens_ana4}, and \ref{tab:sens_ana5}. An example of the resulting reward models with varying values of $\beta$ for each function is shown in Figures \ref{fig:beta_1}, \ref{fig:beta_4}, and \ref{fig:beta_5}. 

In all three scenarios, the true achieved reward remains relatively stable across a broad range of $\beta$ values, indicating that the method is not sensitive to the uncertainty coefficient. However, when $\beta$ is less than $2.0$, the approximate reward consistently overestimates the true reward, which can lead to errors in the converged policy. Depending on the desired conservativeness of the reward model, it seems best to choose values of $\beta$ greater than or equal to $2.0$.

\subsection{Objective Comparison on Robotic Task}
Finally, the different objectives were evaluated on the physical sorting task described in Section \ref{sec:phys_setup}, in which a robotic manipulator has to grasp and sort recyclable objects. An initial dataset consisting of $160$ expert and $340$ random demonstrations was first collected. The expert demonstrations were generated by hand-guiding the KUKA collaborative robot to a variety of feasible grasp poses for the assigned object, while the random demonstrations were generated using an exploration policy that sampled actions uniformly within the action bounds. An expected reward ensemble consisting of $5$ networks ($N=5$) was then trained on the initial dataset. The same expected reward model was subsequently used to train each objective across $8$ initialization seeds with $\beta=2.0$. The learned policies were evaluated on $3$ workspace configurations containing a total of $5$ bottles and $5$ cans. For every policy, $10$ grasps were executed on the $3$ workspace configurations without action perturbations, followed by $10$ grasps with adversarial action perturbations of $\pm2$ cm in each translational direction and $\pm6^\circ$ in each rotational direction. Across the $8$ initialization seeds, this amounts to $80$ grasp attempts without noise and $80$ grasp attempts with perturbations for each objective, resulting in a total of $800$ grasp attempts across the entire experiment.
The grasp success rates across all seeds are shown in Table \ref{tab:grasp_success_rates}, while the per-seed success rates without noise, with noise, and combined are shown in Tables \ref{tab:without_noise_results} \ref{tab:with_noise_results}, and \ref{tab:overall_noise_results}.
